# Immutable historical research archive

All inventoried files preserve original bytes. They are original project code,
synthetic fixtures and reports, published under Apache License 2.0. Third-party
libraries, pretrained weights and external datasets are not included.

This is an archive, not the supported implementation. Commands, dependency
versions, incomplete schemas and status statements in archived documents describe
the original experiments. Use the repository root README for current commands.

Successful train-only diagnostics and failed held-out/answerability results remain
historical observations. The original checkpoints and tokenizer binaries are
unavailable here; exact numerical reproduction of those observations is not
claimed. New public-architecture runs have separate identities and reports.

`inventory.json` accounts for every original member and documents omissions.
`README.md` is the single archive annotation outside the original inventory.
